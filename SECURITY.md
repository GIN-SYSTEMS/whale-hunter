# Security Policy

## Supported Versions

We are committed to keeping the **Whale Hunter** ecosystem secure. Since this is a local-first, sovereign intelligence tool, we prioritize security updates for the latest major releases.

| Version | Supported          |
| ------- | ------------------ |
| 11.0.x  | :white_check_mark: |
| < 11.0  | :x:                |

## Our Security Philosophy

**Whale Hunter** is built on the principle of **Sovereign Data**. 
1. **Local-Only:** Your API keys, wallet watchlists, and logs never leave your machine. There is no telemetry or hidden backend.
2. **Provider Agnostic:** We do not force you to use specific nodes; you control your data source.
3. **Open Source:** Every line of code is transparent and auditable.

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please do not report it via public GitHub issues. Instead, help us keep the community safe by following these steps:

1. **Private Report:** Please send a detailed report of the vulnerability to the lead maintainer via GitHub Private Vulnerability Reporting or by opening a "Security" advisory.
2. **Details to Include:**
   - A description of the vulnerability.
   - Steps to reproduce (if applicable).
   - Potential impact.
3. **Response Time:** We aim to acknowledge all security reports within **48 hours** and provide a timeline for a fix.

## Disclaimer

As stated in the license (GPL3), this software is provided "as-is". Users are responsible for securing their own `.env` files and environment variables. **Never share your `.env` file or private keys with anyone.**
